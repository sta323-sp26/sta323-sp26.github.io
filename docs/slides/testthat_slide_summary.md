The "Testing with testthat" lecture introduces the importance of testing in R package development and explains how the testthat package streamlines the process. It covers how to set up a package to use testthat, the structure and naming conventions for test files, and fundamental concepts like tests, expectations, and running tests within development workflows. The lecture highlights core expectation functions (such as expect_equal, expect_identical, expect_true, and expect_error), demonstrates best practices for testing—including error handling, testing edge cases, skipping tests under certain conditions, and using snapshot tests for complex outputs—and emphasizes the role of tests as both documentation and a tool for collaborative, maintainable software development. It also introduces the principles of Test-Driven Development (TDD) and explains how a thorough test suite supports reliable, reproducible code.
